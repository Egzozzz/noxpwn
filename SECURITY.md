# Security Policy

## Supported Versions

Only the latest release of **NOXPWN** receives security updates and bug fixes:

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within **NOXPWN**, please report it responsibly:

1. **Do not** create a public GitHub issue for sensitive security vulnerabilities.
2. Send an email with details and reproduction steps to the repository maintainer via GitHub Security Advisories or direct message.
3. Include the following details:
   - Type of issue (e.g. command injection, path traversal, sensitive data exposure).
   - Steps to reproduce or proof-of-concept.
   - Operating system and Python version.

We appreciate your efforts to responsibly disclose findings and will work to address verified issues promptly.

---

## Authorized Usage & Ethics

**NOXPWN is strictly intended for legal, authorized security assessments and bug bounty programs.**
- You must have explicit, written authorization before testing any target.
- Comply with the target program's rules of engagement, rate limits, and scope.
- The developers assume no liability for misuse, unauthorized testing, or damage caused by this software.
